What your file needs

  • A header row on the first line. Your own column names are fine: the app suggests what each column is and you can correct any suggestion on the next page.
  • Each row needs a genus and species, either in two columns or in one "Organism" column (Saccharomyces cerevisiae Ale-01 is split for you).
  • Everything else is optional: strain, accession numbers (NCYC 505; ATCC 18824), tags, Gram stain, last revival date and interval, media, storage, source lab, notes.
  • Dates read day-first (03/04/2025 is 3 April); YYYY-MM-DD is always safe.
  • Imported strains get collection IDs the same way hand-entered ones do.
