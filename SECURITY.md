# Security

## Reporting a security problem

Please do not open a public issue for a security problem, because that would
show other people how to misuse it before a fix exists.

Instead, use the private route on the repository's page: open the **Security**
tab and choose **Report a vulnerability**. Please include:

- what you found and where in the app,
- the steps to reproduce it,
- the version number (shown on the About page), and
- whether any data was exposed.

You will get a reply as soon as the maintainer can, and a fix will be released
in a new version when one is needed. This is a free project run by one person,
so there is no guaranteed response time.

## Which versions get fixes

Only the latest release. Please upgrade before reporting.

## Your responsibility as the person running an installation

Each installation is run by whoever installed it. The maintainer has no access
to your data and cannot see or recover it. You are responsible for backups,
passwords, who can reach the app, and for following the rules that apply to
your lab. See "Before you rely on it" in the README.
